基本の測定・解析と遠隔受付の骨格を提供しています。周波数走査はNMRController.sweepと専用画面で提供しています。パルス校正も周期数走査・共通位相基準・符号付きサイン近似と専用画面を提供します。T1/T2測定は公開APIに含みません。即時停止命令、進捗イベント、統一エラーコード、TypeScript型定義も未提供です。

READMEは導入の入口、API.mdは呼び出し契約、PROTOCOL.mdは通信の根拠、ANALYSIS.mdは数値処理の規約、FIREBASE.mdは遠隔設定と保守、SPEC.mdは合意した利用方針を扱います。実装を変えた際は該当する契約と本書を更新します。

## 再確認するコマンド

このnmrlink/フォルダで実行します。

```sh
npm ci
npm test
npm run test:demo
npm run test:direct
npm run test:standard
npm run docs:build
npm run test:docs
npm run docs:check
```

npm testはパッケージのテスト、test:demoは模擬装置・解析連携、test:directはグラフ・解析・表示オプションの確認です。docs:build / docs:checkは公開サイトの生成と参照検査です。PoC照合テストはtests/fixtures/poc/に原文のまま保存した参照実装を使います。テスト・ライブラリとも親フォルダに依存しません。test:standardは標準Web UIの再解析とCSV出力、test:docsは表示例とコピー用HTMLの整合を確認します。

Firebaseエミュレーターの連携テストはnpm run test:firebaseです。Java 21以上とローカルポートを使い、実Firebaseには接続しません。デモはnpm run demoで、必要に応じて専用Javaを取得します。詳細は [デモ手順](../examples/demo/README.md) を参照してください。今回の文書整理では実Firebase確認を行いません。
