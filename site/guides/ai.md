# AIと一緒にWeb UIを作る

NMRLinkの使い方をAIに渡して、自分のWeb UIを作れます。[llms.txt](../llms.txt)には、導入方法・API・最小コード例・装置操作の制約をまとめています。

## llms.txtをAIに渡す

ChatGPTなど、利用するAIに次のURLを渡します。

```text
https://masabando.github.io/nmrlink/llms.txt
```

URLを読む機能がない場合や、内容を取得できない場合は、[llms.txtを開いて](../llms.txt)本文をコピーし、会話に貼り付けるか、テキストファイルとして添付してください。URLを渡すだけで自動的に読み込まれるかは、利用するAIやツールによって異なります。

そのうえで、作りたい画面と実行環境を伝えます。npmとViteを使うか、ビルドせず静的HTMLを配信するかを指定すると、適切なimport方法を選びやすくなります。

## 静的HTMLを作る依頼例

次の文章をコピーして使えます。必要な機能や見た目は変更してください。

```text
以下のNMRLinkのドキュメントを読んで、自作Web UIを作ってください。
https://masabando.github.io/nmrlink/llms.txt

NMRLinkのリポジトリ直下にindex.htmlを置き、Live Serverで配信します。
npmやビルドは使わず、JavaScriptのES modulesを相対URLから読み込んでください。

必要な機能：
- 装置への接続・切断
- 測定条件の入力とSingle測定
- FIDとFFTのグラフ表示
- 生データJSONの保存
- 接続状態とエラーの表示

通信・測定・解析・グラフ・保存にはNMRLinkの公開APIを使ってください。
接続はボタンクリックから呼び、処理中のボタン状態を適切に制御してください。
測定コマンドの自動再送はしないでください。
測定条件の初期値は例であることを画面に明記してください。
完成したHTMLと、ファイルの配置・起動方法を示してください。
```

同名のファイルがある場合は、上書きせず別名で保存してください。実機への直接接続には、対応する装置・Web Serial対応ブラウザ・HTTPSまたは同じPCのlocalhostが必要です。

## npmを使う依頼例

```text
以下のNMRLinkのドキュメントを読んで、Viteのブラウザアプリを作ってください。
https://masabando.github.io/nmrlink/llms.txt

npm install nmrlinkで導入し、nmrlink、nmrlink/graphs、nmrlink/browserを使います。
接続・Single測定・FID/FFT表示・JSON保存ができる画面にしてください。
NMRControllerで操作状態とエラーを扱い、通信やFFTを独自実装しないでください。
画面を破棄するときの切断と監視の終了処理も説明してください。
依存関係、ファイル一式、起動方法を示してください。
```

使いたいフレームワークや既存プロジェクトがあれば、それも伝えてください。NMRLink本体はUIフレームワークに依存しません。

## 作った画面を確かめる

最初に画面の表示、入力欄、エラー表示を確認します。実機なしで試したい場合は、AIに「測定記録の形式に沿った模擬データで、解析とグラフ表示を確認したい」と追加で伝えられます。模擬データの表示成功は、実機との接続や測定の確認とは別です。

実機を使う前に、周波数・パルス周期数・位相・測定間隔・積算回数を装置と試料に合わせて確認してください。生成されたコードに、意図しない自動測定や自動再送がないことも確認します。NMRLinkは測定中の即時停止に対応していません。

動かないときは、エラーメッセージと関連コード、ブラウザ・OS・配信方法をAIに渡します。API名や戻り値が不明な場合は、[APIリファレンス](../reference/api.md)と照らし合わせます。遠隔接続は実環境で未検証のため、実機で使う画面は直接接続から始めてください。
