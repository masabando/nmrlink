# パルスを校正する

[パルス校正の画面を開く](../../examples/standard/pulse.html)

周波数を固定し、第1パルスの周期数を変えてSingle測定します。信号の絶対値・符号付き信号を比較し、サイン近似から90°・180°パルスの周期数の候補を求めます。

## 測定の流れ

1. 周波数調整で選んだ値を「固定周波数」へ入力します。他の測定画面は先に切断してから接続します。
2. 走査の開始・終了・刻み幅と積算回数を確認します。初期範囲は5〜80周期、5周期刻み、各点64回積算です。
3. FFT範囲・窓・ピーク探索帯域を決め、「走査開始」を押します。周波数・位相などは走査中固定します。
4. 初期表示の「絶対値」で振幅の山と谷を確認します。「符号付き信号」へ切り替えると最初の正の山と、その後の符号反転を確認できます。一覧の周期数を押すとFID・FFTを表示します。
5. サイン近似が有効なら「近似値を候補欄へ」で整数周期の候補を確認します。測定画面への移動前に切断し、候補を手動で入力します。
6. 必要なJSON・CSV・PNGを保存します。

候補欄への反映は記録用で、装置に命令は送りません。初期値21・42周期は確定した校正値ではなく、装置と試料に合わせて確認する値です。

絶対値の表示はラビ振動の振幅を確認するためのもので、負の信号は正側に折り返されます。山や谷だけから90°・180°を確定せず、符号付き解析と位相の一致も確認してください。表示の切り替えは再測定や生データの変更を行いません。

## 符号を残して比較する

FFTの振幅は常に非負なので、これだけでは信号の符号反転が分かりません。このページでは、探索帯域内で全点のFFTパワーを足して共通周波数を選び、強い信号群の共通方向から位相基準を決めます。各点の複素成分をその方向へ射影し、符号付き信号と直交成分を求めます。

各点を別々に位相合わせすることはありません。自動基準は短い周期数の強い信号を正方向に揃えます。初期の短いパルスから測定し、最初の山を見落とさない範囲を選んでください。

「選択点を位相基準にする」で手動指定でき、追加位相補正を全点へ適用できます。再解析では測定し直さず、生データを変更しません。位相基準を変えると候補欄をクリアするため、結果を再確認してください。

## 候補とサイン近似

実測の候補は最初の正の山を90°、その後の正から負へのゼロ交差を180°として表示します。ゼロ交差には隣接点の線形補間を使います。

近似モデルは符号付き表示で `A sin(πp / (2 p90)) + B`、絶対値表示で `A |sin(πp / (2 p90))| + B` です。180°候補は `2 p90` として表示します。

異なる周期数の3点以上があればサイン近似を試みます。最初の山・ゼロ交差が未測定、位相が不揃い、一致度が低い場合も推定を表示し、問題点は注意書きで示します。近似曲線・R²と各点の波形を確認してください。測定範囲が狭いと周期が一意に決まらず、範囲外への外挿になる場合があります。ゼロ信号や不正なデータなど、計算できない場合だけ近似を表示しません。

「近似値を候補欄へ」は現在選択している表示の近似値を使います。絶対値では符号反転が見えないため、候補は参考値として確認してください。

## 停止・保存・デモ

走査は最大201点で、周波数調整と同じ走査エンジンを使います。停止は現在の測定完了を待って次の点へ進まない方式です。失敗時は自動再送せず、取得済みの点を保持します。新しい走査では記録を置き換えるため、必要なデータは先に保存してください。

- 全データJSON：各点の補正前データ、測定・解析条件、位相基準、符号付き解析と近似結果。
- 校正CSV：周期数、符号付き信号、絶対値、直交成分、基準周波数・位相。
- PNG：現在選んでいる表示と、計算できたsinまたは|sin|の近似曲線。
- 選択点の生データJSON：標準測定画面の「JSONを開く」で再解析できます。

パルス校正画面の「全データJSONを開く」で保存した走査を復元できます。装置への接続や再測定は不要です。絶対値・符号付き信号の切り替え、各点のFID・FFT、位相基準の再解析、再保存ができます。保存された生データから解析をやり直し、手動基準と追加位相補正も復元します。途中停止した走査も開けます。

読み込みは32 MiB以下・最大201点に対応します。走査中は開けません。読み込み成功時に現在の記録を置き換え、失敗時は保持します。測定画面で開く場合は選択点の生データJSONを使います。

「パルス走査デモ」は既知の90°＝21周期の合成信号で動作を試せます。実機へ命令は送らず、測定精度の検証には使いません。画面と保存データに模擬データと記録します。

## 測定時間の見込み

測定条件を変更すると、測定の見込み時間を更新します。積算回数 ×（繰り返し間隔 ＋ 取得時間40.96 ms ＋ Doubleの場合のパルス間隔）で計算し、走査は全点を合計します。走査画面には1点あたりの時間も表示します。通信や装置の応答待ちなどの追加時間を含まない概算で、デモの再生時間ではありません。

パルス周期数のグラフは横軸を0から表示します。未測定の0周期の点は補いません。

## 自作UIでグラフを描く

[パルス応答の表示例とコピーして使えるコード](./pulsegraph.md)を参照してください。標準Web UIと同じライブラリ関数を使えます。

信号がゼロで近似や共通基準を計算できない保存記録も、生データと波形を確認するために開けます。推定できない理由は画面に表示します。
