# 解析範囲を変える

取得済みデータを切り出して再解析します。ボタンで区間を切り替えると、FID上の帯とFFTが変わります。再測定は行いません。

<!-- example:range -->

## 解析オプション

| オプション | 既定値 | 内容 |
| --- | --- | --- |
| startMs / endMs | 1 / 5 | 開始を含み、終了を含まない区間 [ms] |
| tailPoints | 100 | ベースラインに使う取得末尾の点数 |
| truncate | true | 補正後に0へ向かって整数化 |
| window | hann | hannまたはrect |

4点以上の区間が必要です。範囲外や不正値はthrowします。解析区間を短くすると周波数分解能1/Tが粗くなります。ゼロ埋めでビン間隔を細かくしても、この分解能は改善しません。
