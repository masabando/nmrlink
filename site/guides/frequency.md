# 周波数を調整する

[周波数調整の画面を開く](../../examples/standard/frequency.html)

周波数を一定間隔で変えてSingle測定し、同じFFT条件でピーク振幅を比較します。測定した範囲で最大振幅となった周波数を、設定の候補として確認できます。

## 使い方

1. 他の測定画面が装置を使っている場合は先に切断し、この画面で接続します。
2. 開始・終了周波数、刻み幅、パルス周期数・位相、各点の積算回数を確認します。
3. FFTの時間範囲・窓・ピーク探索帯域を指定して「走査開始」を押します。
4. 周波数応答と最大振幅の候補を確認します。一覧の周波数を押すと、その点のFID・FFTを表示します。
5. 必要なJSON・CSV・PNGを保存し、切断します。候補を使う場合は測定画面の周波数へ手動で入力します。

「周波数走査デモ」は模擬データを使い、装置へ命令を送りません。デモ結果は画面と保存データにDEMOまたはdemoと記録します。

各点の積算回数の初期値は64回です。

## 走査と停止

最大201点です。終了周波数が刻み幅のグリッドに合わない場合、その手前の点まで測定します。開始前に予定点数と最終点を表示します。

走査中は測定・解析条件を固定し、接続・切断・追加走査を受け付けません。「現在の測定後に停止」は次の点の開始を止める機能です。進行中の測定は完了を待ちます。通信や解析が失敗した場合もそこで中断し、取得済みの点を保持します。自動再送は行いません。

新しい走査では前回の記録を置き換えます。必要なデータは開始前に保存してください。ページを閉じると画面内の記録は失われます。

## 候補の読み方

末尾100点でベースライン補正し、指定した時間範囲・窓で複素FFTを行います。そのうちピーク探索帯域内の最大振幅を各周波数の評価値にします。下のFFT図の表示範囲（±10 kHz）と、評価に使う探索帯域は別です。

この候補は測定範囲・刻み幅・測定条件に依存します。最大が範囲の端なら、範囲を広げて再確認してください。振幅が全点ゼロなら候補の採用はできません。ノイズや別のピークも評価に入るため、選択点のFID・FFTを確認して判断します。二次近似や未測定点の最適値の推定は行いません。

## 保存する内容

- 全データJSON：走査条件・解析条件・各点の評価値と補正前の全2048点。
- 走査CSV：設定周波数・帯域内ピーク振幅・ピーク位置。生データは含みません。
- PNG：周波数応答のグラフ。
- 選択点の生データJSON：標準測定画面の「JSONを開く」で再解析できます。

全データJSONは走査専用の形式です。測定画面で開く場合は「選択点の生データJSON」を使ってください。ファイル名の日時は日本時間です。

## 自作UIへ組み込む

NMRController.sweepが走査中の排他制御を行い、通信・Single測定には共通のNMRDeviceを使います。

```js
const stop = new AbortController();
const response = await controller.sweep(parameters, {
  startHz: 400000, endHz: 404000, stepHz: 1000,
  analysis: { startMs: 1, endMs: 5, window: "hann", minHz: -3000, maxHz: 3000 },
  signal: stop.signal,
  onPoint(point, completed, total) {
    console.log(point.frequencyHz, point.amplitude, completed, total);
  },
});
// 別の停止ボタンからstop.abort()を呼びます。
```

## 保存した走査を開く

「全データJSONを開く」で保存した周波数走査を復元できます。装置への接続や再測定は不要です。生データから周波数応答・最大振幅の候補・各点のFID／FFTを再計算し、JSON・CSV・PNGを再保存できます。

32 MiB以下・最大201点に対応し、途中停止した走査も開けます。走査中は読み込めません。成功時に現在の記録を置き換え、失敗時は保持します。パルス校正の全データJSONや単独の測定JSONは対象外です。

## 測定時間の見込み

測定条件を変更すると、測定の見込み時間を更新します。積算回数 ×（繰り返し間隔 ＋ 取得時間40.96 ms ＋ Doubleの場合のパルス間隔）で計算し、走査は全点を合計します。走査画面には1点あたりの時間も表示します。通信や装置の応答待ちなどの追加時間を含まない概算で、デモの再生時間ではありません。
