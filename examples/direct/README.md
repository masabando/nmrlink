# 直接接続の最小サンプル

自作Web UIへの組み込み方を理解するための最小例です。そのまま使う標準Web UIとは役割を分けます。

秘密鍵・.env.local・利用許可ファイルがない、直接接続用のチェックアウトで、nmrlink/全体をLive Serverなどの静的Webサーバーで公開し、examples/direct/index.htmlを開きます。nmrlink/のルートでLive Serverを起動してください。examples/direct/だけを公開するとライブラリの相対参照が届きません。

HTTPSまたは同じPCのlocalhostと、Web Serial対応のデスクトップブラウザを使います。装置を使っているPythonやほかのタブは先に切断してください。接続→条件確認→測定→JSON保存→切断の順です。

初期値は周波数402000 Hz、第1パルス20周期、第2パルス40周期、積算128回です。すべての装置・試料に適した条件ではありません。即時停止は実装していません。

結果は補正前の生データです。新しい測定の成功時に置き換えます。測定失敗時には前回の結果を残します。ページを閉じる・再読み込みすると消えます。Firebaseやサーバープログラムは不要です。

自作UIでの呼び出し方は [APIリファレンス](../../docs/API.md) を参照してください。遠隔用の秘密設定を置いた作業フォルダ全体を配信しないでください。

## GitHub Pagesで使う

ドキュメントサイトの「直接接続サンプルを開く」から利用できます。公開用にはnpm run docs:buildで必要なサンプルとライブラリだけをdist/pages/へコピーします。Pagesでの生成・配信では秘密設定を含むチェックアウト全体を公開しません。[公開手順](../../docs/PAGES.md) を参照してください。

## 波形とスペクトル

測定後に2チャンネルの時間波形と複素FFTの振幅を表示します（Doubleではエコーを含む時間波形）。末尾100点平均を差し引いて0に向かって整数化し、FID表示は0〜10 msの500点、縦軸は1〜5 msの値で自動調整し、範囲外の先頭信号はクリップします。FFTは1〜5 ms（終端を含まない）の200点にHann窓を適用します。表示範囲は受信周波数から±10 kHz、縦軸は自動調整です。解析条件の入力欄は設けません。保存JSONは補正前のままです。新しい測定が失敗した場合は前回の結果・グラフを保持し、取得後の解析に失敗した場合はグラフを消して新しい生データを保存可能にします。

最大ピークは表示区間に限らず、FFTの全周波数から振幅最大のビンを探し、受信周波数からの差として表示します。表示範囲外の場合も明記します。補間による周波数推定は行いません。

グラフは横幅に応じて再描画し、高さを280 pxに固定します。FID上の薄い青の帯と破線はFFT解析区間1〜5 msです。画面幅の変更では保持済みデータだけを再描画し、測定を再実行しません。

## コードを読む順番

index.htmlは画面、app.jsはフォームとイベントの結び付けです。操作状態・排他・結果保持はNMRController、補正・FFT・ピーク探索はanalyzeMeasurement、グラフ生成とリサイズはNMRGraphs、JSON保存はsaveMeasurementへ任せています。描画実装はサンプル内に置かず、packages/nmrlink/src/graphs.jsを使います。組み込みの順番は [自作Web UIの作り方](../../docs/UI.md)、各APIの引数・例外処理・終了処理は [APIリファレンス](../../docs/API.md) を参照してください。

線色はNMRGraphsのcolorsオプションでdata1・data2・fftを個別に指定できます。未指定の色は既定値を使い、リサイズ後も維持します。例と凡例の扱いは [自作UIの手順](../../docs/UI.md) を参照してください。
